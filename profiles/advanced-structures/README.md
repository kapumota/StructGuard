### Perfil advanced-structures

#### Propósito

Este perfil agrupa contratos experimentales para estructuras avanzadas como Fenwick Tree, Segment Tree, DSU, heaps, B-Trees y estructuras de cadenas.

El perfil no forma parte del flujo principal de CI. Se conserva como material experimental para extender StructGuard hacia estructuras más complejas.

#### Uso

```bash
structguard profiles validate profiles/advanced-structures/profile.yml

structguard contract check profiles/advanced-structures/contracts/advanced_structures.sgdsl
```
